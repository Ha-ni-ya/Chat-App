# Chat Application – Task 2 (CodTech Internship)

## Project Overview

A responsive chat application interface developed as part of the CodTech IT Solutions internship. The project focuses on creating a user-friendly messaging interface using web technologies, with a clean layout for sending and displaying chat messages.

## Features

- Responsive chat interface for desktop and mobile devices.
- User and bot message bubbles with separate styling.
- Message input field and send button.
- Scrollable message display area.
- Clean and user-friendly interface.
- Mobile-responsive layout.

*Additional features such as real-time messaging, timestamps, login and dark mode should be listed only if they are implemented in the application.*

## Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling, layout and responsive design.
- JavaScript – Interactive functionality and message handling.


## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in a code editor.
3. Open `index.html` in a web browser.
4. Use the chat input field to interact with the application.

## Key Concepts Demonstrated

- HTML page structure and semantic elements.
- CSS Flexbox and layout styling.
- Responsive web design using media queries.
- JavaScript event handling.
- Dynamic message display.
- CSS transitions and hover effects.
